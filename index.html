1 Що таке одновимірний масив (список) у Python?

У звичайну змінну можна покласти лише одне значення: x = 5. Якщо нам треба зберегти оцінки 30 учнів класу або температуру за місяць, заводити 30 окремих змінних незручно. Для цього використовують список (list) — це впорядкована послідовність даних під одним спільним іменем. Елементи записуються через кому в квадратних дужках [ ]:

# Порожній список:
a = []

# Список оцінок (числа):
grades = [10, 8, 12, 7, 9]

# Список учнів (рядки тексту):
names = ["Анна", "Богдан", "Олег"]
2 Індексація: Чому рахунок починається з НУЛЯ?

Кожен елемент списку має свій порядковий номер — індекс. Головне правило Python: нумерація починається з 0, а не з 1!

Пряма індексація (зліва направо): a[0] — перший елемент списку
a[1] — другий елемент
a[2] — третій елемент
Зворотна індексація (справа наліво): a[-1] — останній елемент списку
a[-2] — передостанній елемент
a[-len(a)] — найперший елемент
⚠️ Помилка IndexError: list index out of range виникає, коли ви звертаєтеся до індексу, якого немає у списку (наприклад, у списку з 3 елементів спробували викликати a[5]).

📘 Конспект уроку №19:

1. Що таке сортування і навіщо воно потрібне?

Сортування — це впорядкування елементів списку за певним правилом:

  • За зростанням (неспаданням): кожен наступний елемент більший за попередній або дорівнює йому: [1, 3, 5, 8, 12].
  • За спаданням (незростанням): кожен наступний менший або дорівнює попередньому: [12, 8, 5, 3, 1].

💡 Навіщо сортувати? У відсортованому списку шукати дані в рази швидше (як у словнику чи класному журналі за алфавітом). Також це основа визначення переможців змагань, формування топ-рейтингів тощо.

2. Вбудовані засоби Python: метод sort() та функція sorted()

У мові Python розробники вже створили надшвидкі готові інструменти:

Метод a.sort() (Змінює сам список)

Сортує список «на місці». Старий порядок елементів зникає.

a = [5, 2, 9, 1]

a.sort()
print(a)  # [1, 2, 5, 9]

a.sort(reverse=True)
print(a)  # [9, 5, 2, 1]
Функція sorted(a) (Створює новий список)

Початковий список a залишається незмінним, а утворюється новий список b.

a = [5, 2, 9, 1]

b = sorted(a)
print(a)  # [5, 2, 9, 1] (не змінився!)
print(b)  # [1, 2, 5, 9] (новий!)

3. Алгоритми сортування «під капотом» (Вимоги програми)

Щоб розуміти, як комп'ютер упорядковує дані всередині пам'яті, у 9 класі вивчають два алгоритми:

Алгоритм 1: Метод обміну («Бульбашка»):

Ідея: проходимо по списку зліва направо, порівнюємо сусідні елементи a[j] та a[j+1]. Якщо лівий більший за правий — міняємо їх місцями. Найважче число поступово «спливає» у самий кінець списку. 

# Сортування списку довжиною n за зростанням методом обміну:
n = len(a)
for i in range(n - 1):
    for j in range(n - 1 - i):
        if a[j] > a[j + 1]:
            # Обмін двох сусідніх елементів у Python:
            a[j], a[j + 1] = a[j + 1], a[j]
Алгоритм 2: Метод вибору (Selection sort):

Ідея: знаходимо найменший елемент серед несортованої частини списку за допомогою min() і міняємо його місцями з першим несортованим елементом. Потім повторюємо для решти списку. 

n = len(a)
for i in range(n - 1):
    m = min(a[i:])          # шукаємо мінімум від i-го до кінця
    ind = a.index(m, i)     # знаходимо його номер
    a[i], a[ind] = a[ind], a[i]  # міняємо місцями

3. Зрізи рядків (Slices) — як вирізати частинку тексту

Зріз дозволяє взяти частину рядка за формулою: рядок[початок : кінець : крок]

⚠️ Головне правило зрізів: символ із кінцевим номером у результат НЕ ВКЛЮЧАЄТЬСЯ! (точно як число у range). Наприклад, s[0:3] візьме індекси 0, 1, 2 (всього 3 букви, а індекс 3 вже не увійде!).
Приклади для s = "Інформатика":
s[0:5] → "Інфор" (з 0 по 4 індекси)
s[:3] → "Інф" (якщо початку нема — береться від початку)
s[5:] → "матика" (якщо кінця нема — береться до кінця)
Зрізи з кроком:
s[::2] → "Іфраиа" (кожен другий символ: 0, 2, 4, 6, 8, 10)
s[::-1] → "акитамрофнІ" (крок -1 розгортає рядок задом наперед!)
s[2:8:2] → "фра" (індекси 2, 4, 6 через один символ)
